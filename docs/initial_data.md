# Initial data

Any arbitrarily chosen data for the metric and sources in the 3+1 decomposition of the Einstein Equations will not necessarily be physical. The purpose of generating initial data is to solve the initial conditions equations in the ADM formalism to generate data that is consistent with the Hamiltonian and momentum constraints of GR. This initial data can then be used in a time evolution using numerical relativity codes like GRTeclyn.

Initial data methods for GRTeclyn are still under construction, but we currently support [**TwoPunctures**](two_punctures.md) initial data for binary black hole mergers.

We soon plan to add support for restarting from hdf5 checkpoints previously generated by GRChombo or the GRTresna initial data solver. In the longer term we will develop a native initial data solver within GRTeclyn.

## Full ADM slice input (LM format 5)

`lm.history_id_file = slice.lmid` selects the radiative-puncture exporter's
format-5 full Cartesian slice. It is mutually exclusive with `lm.id_file` and
`lm.curved_id_file`, and requires a build without `USE_TWOPUNCTURES`.
This channel currently requires a 3D, double-precision build.
The ASCII record declares finite, increasing x/y/z nodes, local interpolation
stencil (2/4/6/8), full covariant gamma_ij and K_ij, lapse and contravariant
shift. Coordinates are relative to `geometry.center`, with Cartesian tensor
components. The reader requires exactly version 5; older formats are unchanged.

The consumer retains nonzero trace K, computes chi=det(gamma)^(-1/3),
h=chi gamma and A=chi(K_ij-gamma_ij K/3), then initialises Gamma^i with the
normal GRTeclyn derivative operator. Lapse/shift choices are explicit in the
file (`provided`/`one`/`precollapsed` and `provided`/`zero`). The exporter writes
the chosen nodal values; ingestion does not silently reset them.

The export grid must cover cell centres and ghosts at every level: extrapolation
aborts. Singular puncture samples, invalid metric/lapse data and malformed
records are rejected. This channel supplies no analytic puncture completion;
off-node accuracy and constraint convergence must be checked before evolving.
See [the standalone transport check](../Tests/LMHistoryDataTest/README.md).
